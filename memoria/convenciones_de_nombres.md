# Convenciones de nombres

- Código C#: PascalCase para tipos, métodos y propiedades; camelCase para variables y parámetros.
- C#: usar sufijo `Async` en operaciones asíncronas; `Dto`, `Request` y `Response` para contratos.
- Base de datos: `snake_case`, claves primarias `id`, fechas en UTC y claves foráneas `<entidad>_id`.
- API: rutas plurales y sustantivas en minúsculas (`/api/ordenes-compra`); no exponer entidades directamente.
- React/TypeScript: componentes en PascalCase; hooks `useX`; archivos coherentes con el componente.
- Términos del negocio: español consistente con el glosario; evitar sinónimos para el mismo concepto.
