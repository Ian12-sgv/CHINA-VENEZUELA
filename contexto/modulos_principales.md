# Módulos principales

| Módulo | Propósito |
|---|---|
| Catálogos | Productos, proveedores, categorías y unidades. |
| Compras | Listas, órdenes, estados y costos. |
| Inspecciones | Verificación, incidencias, fotos y códigos. |
| Logística | Bultos, embarques, tránsito y recepción. |
| Archivos | Evidencias y metadatos de documentos/fotos. |
| Seguridad | Usuarios, roles, permisos y sesiones. |
| Auditoría | Registro inalterable de acciones relevantes. |
| Reportes | Indicadores y consultas operativas. |

La app móvil y la sincronización pertenecen a una fase posterior.
