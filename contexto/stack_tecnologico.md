# Stack tecnológico

- Backend: ASP.NET Core 10 LTS, API REST, OpenAPI, EF Core, Npgsql y PostgreSQL.
- Seguridad: JWT, roles y policies.
- Procesamiento diferido: Worker Service.
- Frontend: React, TypeScript, Vite, React Router, TanStack Query y una tabla operativa tipo AG Grid o equivalente.
- Móvil posterior: Flutter o React Native/Expo, con soporte offline, cámara, escáner y sincronización.

La versión exacta de paquetes y la elección definitiva de móvil se documentarán como decisiones confirmadas.
