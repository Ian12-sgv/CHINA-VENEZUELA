# Frontend React y Vite

## Objetivo

Construir interfaces operativas con React, TypeScript, Vite, Router y TanStack Query.

## Cuándo usarlo

Al crear rutas, formularios, tablas, estado remoto o vistas web.

## Entradas esperadas

Flujo, rol autorizado, endpoint/DTO, patrones visuales y requisitos de interfaz.

## Salida esperada

Componentes y archivos completos, ruta, estados UI, validación y prueba aplicable.

## Reglas que debe respetar

Usar TypeScript estricto; gestionar servidor con TanStack Query; paginar listados grandes en servidor. Cumplir siempre eglas/alcance_cerrado.md, preservar nombres y estructura existente, y pedir autorización antes de ampliar el alcance.

## Flujo de trabajo

1. Leer el contexto, estado, decisiones y reglas pertinentes.
2. Delimitar el cambio pedido y confirmar los supuestos necesarios.
3. Diseñar o implementar solo el resultado solicitado.
4. Validar proporcionalmente el resultado y registrar documentación si corresponde.

$example

## Errores que debe evitar

Usar any, dispersar fetch, cargar todos los datos o duplicar autorización del backend.
