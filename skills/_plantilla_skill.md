# Plantilla para un nuevo skill

Crear una carpeta `skills/<nombre-en-kebab-case>/` con `SKILL.md` y frontmatter `name` y `description`. Mantener el contenido conciso e imperativo.

El skill debe contener: objetivo, entradas requeridas, salida esperada, reglas que respeta, flujo de trabajo, ejemplo de invocación y errores a evitar. Añadir recursos solo si son reutilizables (scripts, referencias o assets) y validar el skill al terminar.
